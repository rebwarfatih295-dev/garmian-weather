# ڕێنمایی دروستکردنی فایلی IPA بۆ ئەپڵیکەیشنی (کەشوهەوای گەرمیان)
دروستکەری ئەپڵیکەیشن: **ڕێبوار مانج علی**

لەم فایلەدا تەواوی کۆدە ئامادەکراوەکانی ئەپلیکەیشنی **کەشوهەوای گەرمیان** بۆ سیستەمی iOS دانراوە کە داتای زیندووی کەشوهەوای (کەلار، ڕزگاری، کفری، خانەقین، باوەنوور، دەربەندیخان، سەرقەڵا) وەردەگرێت و ناوی دروستکەر (**ڕێبوار مانج علی**) لە خوارەوەی ئەپەکە و لە پەنجەرەی دەربارە (ℹ️) جێگیر کراوە.

---

## چۆن فایلی IPA دروست بکەیت بەبێ کۆمپیوتەری Mac (لەسەر Windows):

1. هەژمارێکی بێبەرامبەر لە ماڵپەڕی **GitHub.com** دروست بکە و ئەم فایلانەی ناو ئەم ZIPـە بەرز بکەرەوە ناو Repositoryـیەکی نوێ.
2. بڕۆ ماڵپەڕی **Codemagic.io** و بە هەژماری GitHub بچۆ ژوورەوە (مانگانە ٥٠٠ خولەک بێبەرامبەرە).
3. پرۆژەکەت هەڵبژێرە و پەنجە بنێ بە **Start new build**.
4. دوای ٣ بۆ ٥ خولەک، فایلی **`GarmianWeather.ipa`** بە ئامادەکراوی دەداتە دەستت بۆ داگرتن!

## چۆن فایلی IPA بخەیتە ناو ئایفۆنەکەت؟
1. بەرنامەی **Sideloadly** یان **AltStore** لەسەر کۆمپیوتەری Windows دابەزێنە.
2. ئایفۆنەکەت بە کێبڵ ببەستەرەوە بە کۆمپیوتەرەکەوە.
3. فایلی `GarmianWeather.ipa` ڕابکێشە ناو بەرنامەکە و Apple IDـی خۆت بنووسە؛ یەکسەر ئەپەکە لەسەر ئایفۆنەکەت دادەبەزێت.
